# Homework Hatch Stuff (apple note)

A brief Apple Note jotting a single working formula for use inside [[Homework Hatch (startup)]].

## Content (verbatim)

> **Formula for out-of-state acceptances:**
> `# out-of-state acceptances / total # of applicants`

## Notes

- This is a metric definition, not a calculation result — Traveler is specifying *how* the out-of-state acceptance rate should be computed within the Homework Hatch college-acceptance-% feature.
- The denominator is **total applicants** (not total out-of-state applicants), which means the result is the share of *all* applicants who are out-of-state admits — a slightly non-standard framing. A more conventional out-of-state acceptance rate would use out-of-state applicants as the denominator. The choice of denominator matters for how the metric is displayed to users.

> [!warning] Denominator ambiguity
> Standard out-of-state acceptance rate = out-of-state accepts / out-of-state applicants. This note uses **total applicants** as the denominator instead, which yields a different (typically smaller) number. It's unclear whether this is intentional design or a rough first draft.
